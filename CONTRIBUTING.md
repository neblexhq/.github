# Contributing

Thanks for helping improve the Neblex repositories.

- **Found a mistake or an outdated instruction?** Open an issue, or a pull request with the fix.
- **Have an idea for a worked example?** Open an issue describing the job you want an AI client to build: the systems involved and what should happen to the records.
- **Need help with your own workspace?** Ask Matt inside Neblex or email community@neblex.com instead of opening an issue, so you don't have to share account details in public.

Keep secrets, API keys and customer data out of issues and pull requests.
