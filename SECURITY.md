# Security policy

## Reporting a vulnerability

Report it privately from the repository's **Security** tab: choose **Report a vulnerability**. If the problem isn't tied to a repository, email community@neblex.com and we'll set up a private channel. Please don't open a public issue for a security problem.

Include what you found, the steps to reproduce it, and the affected product area (for example the MCP server at `https://if.neblex.com/mcp`, the web app or the on-premises runtime). We'll confirm we received your report and keep you updated while we fix it.
