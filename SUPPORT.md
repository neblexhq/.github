# Getting help

- **In the product:** ask Matt, the in-product assistant.
- **This repository:** open an issue for a problem or question about what's documented here.
- **Email:** community@neblex.com, or [contact us](https://www.neblex.com/contact).
- **Documentation:** [MCP documentation](https://www.neblex.com/integration-fabric/docs/guide/mcp)

Report security issues privately, not in a public issue. See [SECURITY.md](SECURITY.md).
